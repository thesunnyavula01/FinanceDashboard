# Finance Club Terminal

A paper-trading dashboard for a high-school finance club's yearly stock
simulation. Vite + React + Hono on one Cloudflare Worker, Supabase behind it.

**The architecture document lives at [`PLANNING/DIRECTIONS.MD`](./PLANNING/DIRECTIONS.MD).**
Read it before changing anything: it holds the five non-negotiable rules, the
provider split and its rate-limit arithmetic, the domain model, and the design
system. This file is a pointer so that the document is still picked up
automatically; it is deliberately the only copy of nothing.
